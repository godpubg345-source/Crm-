## 🛡️ Security Audit Findings

### 1. Data Isolation (Multi-Tenancy)
*   **Implementation**: Robust `TenantAwareModel` base class combined with `TenantManager`.
*   **Enforcement**: `BranchMiddleware` and `resolve_branch_from_request` ensure that every request is bound to a specific branch context.
*   **Verification**: ViewSets automatically filter data based on the active branch, preventing cross-tenant data leaks.
*   **Finding**: Logic is leak-proof and correctly handles HQ, Country Manager, and Branch-level roles.

### 2. Encryption at Rest
*   **Implementation**: `EncryptedTextField` using `Fernet` (AES encryption via `cryptography` library).
*   **Usage**: Critical data such as `portal_password` in `ApplicationSubmission` is encrypted at rest.
*   **Finding**: Secure key derivation from `FIELD_ENCRYPTION_KEY` ensures high confidentiality for sensitive credentials.

### 3. Authentication & Sessions
*   **Implementation**: JWT via SimpleJWT with blacklist support.
*   **Hardening**: Access tokens are stored in memory; refresh tokens are persisted in `httpOnly` secure cookies.
*   **Finding**: Robust rotation and logout logic minimize session hijacking risks.
